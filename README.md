# UA TV playlist

Джерело для m3u-editor. Цей репозиторій **лише форматує** список каналів; живість потоків
перевіряє сам m3u-editor зі своєї мережі.

## Як це працює

1. GitHub Action (двічі на день) завантажує публічні плейлисти з `sources.txt`
   (iptv-org, Free-TV та ін.) і для кожного каналу з `channels.json` збирає **всі** знайдені потоки.
2. Пише `playlist.m3u`: кожен потік — окремий запис з однаковим `tvg-id` каналу, українською
   назвою, категорією (`group-title`), логотипом і номером (`tvg-chno`).
3. m3u-editor синхронізується з raw-посиланням на цей файл і далі сам:
   - **auto-merge** обʼєднує записи з однаковим `tvg-id` в один канал: перший — основний, решта — резервні;
   - **Channel Scrubber** після кожної синхронізації перевіряє потоки ffprobe, вимикає мертві,
     вмикає ожилі й перебудовує резерви так, щоб основним був живий потік;
   - **проксі** при падінні потоку під час перегляду перемикає на резервний;
   - **EPG Map** привʼязує програму за `tvg-id` (id каналів з EPG iptvx.one).

## Файли

- `channels.json` — канали: назва, категорія, `tvg_id` (= id у EPG iptvx), логотип, псевдоніми для пошуку.
  Порядок у файлі = порядок і номери каналів.
- `sources.txt` — джерела потоків; порядок = пріоритет потоків.
- `extra_streams.json` — свої потоки: `{"tet-ua": ["http://..."]}`.
